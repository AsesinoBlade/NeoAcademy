# Consistency Editor

A section of a book contradicts other sections. Edit it so it agrees with the CORRECT STATEMENTS given.

Rules:
- Change ONLY the sentences, table cells, formulas, captions and examples that state or depend on the listed facts. Recompute any worked-example numbers that depend on a changed value so the example stays correct.
- Keep everything else exactly as it is: wording, headings, structure, figures, code, charts, notes.
- Do not mention the edit, other sections, "corrections" or reviewers.
- If the section already agrees, return it unchanged.

Output the complete section between <section> and </section>, nothing else.
